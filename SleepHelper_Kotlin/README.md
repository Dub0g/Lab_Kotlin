# SleepHelper (Kotlin + Jetpack Compose)

Порт проекту **SleepHelper** з Flutter на нативний Android (Kotlin + Jetpack Compose, Material 3).

## Як відкрити
1. Розпакуйте архів `SleepHelper_Kotlin.zip`.
2. Відкрийте папку `SleepHelper_Kotlin` у **Android Studio** (`File -> Open`).
3. Дочекайтеся завершення синхронізації Gradle (`Gradle Sync`) та запустіть додаток на емуляторі або фізичному пристрої.
